# CFP Committee Simulator

Pick the winners of college football games and see what the College Football Playoff
committee's ranking, the conference championship games and the 12-team bracket would look
like - with a season forecast (1,000 simulated seasons) of each team's playoff odds.

This repository is the **deployed app only**. It is generated - do not edit it by hand.
The data pipeline, the model training and the tests live in the main project; `publish_app.py`
there copies the app, its modules and the few data files it needs into this repository.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`.
